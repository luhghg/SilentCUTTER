# SilentCutter

Десктопное приложение на Python, которое автоматически вырезает тишину из
видео (jump-cut монтаж — как для нарезок и ютуб-шортсов).

Выбираете видео → приложение находит участки тишины по аудиодорожке →
вырезает их и склеивает оставшееся покадрово точно (без рассинхрона звука) →
опционально распознаёт речь и обрывает звук на мате → сохраняет результат рядом
с исходником как `имя_cut.mp4`.

## Стек

- Python 3.11+
- UI: [customtkinter](https://github.com/TomSchimansky/CustomTkinter) (+ [tkinterdnd2](https://github.com/pmgagne/tkinterdnd2) для drag-and-drop)
- Обработка видео: системный `ffmpeg`/`ffprobe` через `subprocess`
- Распознавание речи (для заглушения мата): [faster-whisper](https://github.com/SYSTRAN/faster-whisper)

## Установка

### 1. Установите ffmpeg

Приложению нужны `ffmpeg` и `ffprobe`, доступные в `PATH`.

**Windows:**

1. Скачайте сборку с https://www.gyan.dev/ffmpeg/builds/ (раздел
   `release essentials`, файл `ffmpeg-release-essentials.zip`).
2. Распакуйте архив, например, в `C:\ffmpeg`.
3. Добавьте `C:\ffmpeg\bin` в переменную окружения `PATH`:
   - Пуск → «Изменение переменных среды текущего пользователя»
   - В разделе «Переменные среды» найдите `Path` → «Изменить» → «Создать»
   - Впишите `C:\ffmpeg\bin`, сохраните и перезапустите терминал.
4. Проверьте установку: откройте новое окно терминала и выполните
   `ffmpeg -version` и `ffprobe -version` — должна появиться версия, а не
   ошибка «команда не найдена».

**macOS:**

```bash
brew install ffmpeg
```

**Linux (Debian/Ubuntu):**

```bash
sudo apt install ffmpeg
```

### 2. Установите зависимости Python

Рекомендуется использовать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск

Из корня проекта:

```bash
python -m silence_cutter.main
```

При старте приложение само проверяет наличие `ffmpeg`/`ffprobe` в `PATH` и,
если их нет, покажет понятное сообщение в лог-поле вместо трейсбека.

## Использование

1. Нажмите «Выбрать видео» или перетащите видеофайл в окно.
2. При необходимости настройте параметры:
   - **Порог тишины, dB** — насколько тихо должно быть, чтобы участок
     считался тишиной (по умолчанию −40 dB, диапазон −60…−20).
   - **Мин. длина тишины, сек** — минимальная длительность паузы, которая
     будет вырезана (по умолчанию 0.5 с).
   - **Padding, сек** — сколько добавить в начало и конец каждого
     оставшегося сегмента речи, чтобы не обрезать слова (по умолчанию
     0.15 с).
   - **Экспортировать таймкоды** — сохранить рядом `.txt` со списком
     оставленных сегментов в формате `HH:MM:SS.mmm`, чтобы перенести резы
     в Premiere/DaVinci вручную.
   - **Заглушать мат** (по умолчанию выключено) — после резки тишины
     распознаёт речь и обрывает звук на нецензурных словах. Открывает
     ещё три параметра:
     - **Модель Whisper** — `tiny`/`base`/`small`/`medium`, компромисс
       между скоростью и точностью распознавания (по умолчанию `small`).
       При первом запуске модель скачивается из интернета — это разовая
       операция, следующие запуски используют кэш.
     - **Сколько слышно от слова до обрыва, сек** — сколько от начала
       слова остаётся слышно перед тем, как звук пропадёт (по умолчанию
       0.05 с) — мат остаётся узнаваемым, но формально зацензурен.
       У самого обрыва короткое затухание (20 мс), чтобы не было
       слышимого щелчка.
     - **Хардкор-режим** (по умолчанию выключено) — ищет корень мата в
       любом месте слова, а не только в начале (ловит слова вроде
       «распиздяй», «выблядок» — мат после приставки). Ловит больше,
       но и чаще ошибается на обычных словах, где корень мата случайно
       оказался внутри — включайте, если важнее ничего не пропустить,
       чем не задеть лишнего.
3. Нажмите «Обработать». Прогресс и шаги отображаются в лог-поле снизу.
   Обработку можно прервать кнопкой «Отмена» в любой момент.
4. По завершении результат сохраняется рядом с исходником как
   `имя_cut.mp4`, а в логе появится статистика: исходная и итоговая
   длительность, сколько вырезано (в секундах и процентах), количество
   склеек и (если включено заглушение) сколько слов было заглушено.

### Список запрещённых слов и исключений

`silence_cutter/data/profanity.txt` — корни слов для заглушения (по
одному в строке, сравнение идёт по началу слова после нормализации).
`silence_cutter/data/whitelist.txt` — слова-исключения, которые никогда
не заглушаются, даже если начинаются с одного из корней (например,
«мандарин» начинается с корня «манда», но не имеет отношения к мату). Оба файла
можно редактировать вручную — строки, начинающиеся с `#`, и пустые строки
игнорируются.

## Тесты

Логика расчёта сегментов (детект тишины, инверсия, padding, склейка
близких сегментов) и логика поиска мата (нормализация слов, whitelist,
padding/lead, склейка интервалов) покрыты юнит-тестами без реального
видео и без Whisper/ffmpeg:

```bash
pip install pytest
pytest
```

## Структура проекта

```
silence_cutter/
    main.py             — запуск приложения
    ui.py                — окно и виджеты (customtkinter)
    detector.py           — детект тишины и расчёт сегментов (чистая логика)
    cutter.py             — сборка filter_complex и запуск ffmpeg
    ffprobe.py            — метаданные видео (длительность, fps, разрешение)
    transcriber.py         — распознавание речи (faster-whisper)
    matcher.py             — поиск мата в словах (чистая логика)
    censor.py              — обрыв звука на мате через ffmpeg
    data/
        profanity.txt       — корни матерных слов
        whitelist.txt        — исключения
tests/
    test_detector.py    — юнит-тесты логики сегментов
    test_cutter.py       — юнит-тесты сборки filter_complex
    test_matcher.py       — юнит-тесты поиска мата
    test_censor.py        — юнит-тесты построения фильтра заглушения
requirements.txt
```
