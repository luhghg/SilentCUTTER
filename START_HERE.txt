SilentCutter — как запустить (Windows)
========================================

Программа автоматически вырезает тишину из видео и умеет заглушать мат.

ШАГ 1. Скачать
----------------
Скачайте файл SilentCutter.exe по ссылке (её пришлёт тот, кто скинул
вам эту программу). Ничего устанавливать не нужно — ffmpeg уже встроен
прямо в exe-файл.

Windows/антивирус может поругаться "неизвестный издатель" — это
нормально для программы не из официального магазина, нажмите
"Всё равно выполнить" / "Подробнее" → "Выполнить в любом случае".

ШАГ 2. Запустить
-------------------
Дважды кликните SilentCutter.exe. Первый запуск может занять
несколько секунд дольше обычного — это нормально.

ШАГ 3. Как пользоваться
------------------------
1. Нажмите "Выбрать видео" (или перетащите видео в окно)
2. Нажмите "Обработать"
3. Подождите — в окне будет видно, на каком шаге программа
4. Готовый файл появится рядом с исходным видео с припиской "_cut"

Если что-то не работает — сделайте скриншот окна с текстом ошибки
и отправьте тому, кто вам скинул эту программу.


---
Альтернатива (если exe-файл по какой-то причине не подходит):
в архиве есть install.bat и Run_SilentCutter.bat — это запасной
вариант, который сам ставит Python и ffmpeg из исходников программы.
